# Hardcore Loot Overhaul v0.5 — 奇跡の戦利品（検証版）

- v0.4の既存報酬を維持し、250個の対象テーブルに独立した超低確率プールを追加します。
- 序盤0.1%、中盤0.2%、終盤0.3%（チェスト1回の抽選につき）。
- 初期報酬はバニラのエンチャント金リンゴ、ネザライト強化鍛冶型、ネザライトの欠片。
- `miracle_v05.json` を変更して再ビルドすると確率・報酬を変更できます。ゲーム内設定ではありません。
- Simply Swords 1.70.2 / Simply More 1.3.0 alpha5 のJARは解析対象ですが、独自のユニーク武器生成処理を壊すおそれがあるため**追加抽選は初期状態OFF、ONでもビルド停止**します。未検証の武器IDは追加していません。
- GitHub Actionsでビルドしてください。実際のNeoForge起動検証は未実施です。
- `/loot give @s loot minecraft:chests/ancient_city` などで試せますが、低確率のため短い試行では出ないことがあります。

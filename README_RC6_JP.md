# RC6 Apotheosis 8.8.0連携

Apotheosis 8.8.0のJARに含まれる公式GLM `apotheosis:affix_loot` と `apotheosis:gems` のデータ形式を使い、HLOの289対象テーブルに段階別の追加抽選を付与します。Apotheosisの既存抽選は残ります。

|段階|アフィックス追加抽選|宝石追加抽選|
|---|---:|---:|
|序盤|3%|4%|
|序盤〜中盤|6%|8%|
|中盤|10%|13%|
|中盤〜終盤|15%|20%|
|終盤|23%|30%|
|最高難易度|32%|42%|

抽選の追加であり、宝石の等級やアフィックスのレアリティを直接指定するものではありません。元のApotheosisの出現確率に加算されるため、実際の最終出現率とは異なります。

**Apotheosis 8.8.0が必須です。** 同JARはNeoForge 21.1.235以上とPlacebo 9.9.2以上を要求しています。GitHub ActionsのビルドNeoForge版を21.1.235に更新しました。

**注意**: JSON構造検証のみ実施。Minecraft実機およびGitHub Actionsビルドは未検証です。新規テストワールドで確認してください。

# Hardcore Loot Overhaul v1.0 RC2 — 豪華報酬版

v1.0 RC1をベースに、通常報酬・MOD素材報酬・追加プレミアム報酬を増量したバージョンです。既存戦利品の置き換えは行いません。

| 難易度 | バニラ追加抽選 | MOD素材追加抽選 | プレミアム追加抽選 |
|---|---:|---:|---:|
| 序盤 | 27% | 8% | 11% |
| 序盤〜中盤 | 35% | 12% | 16% |
| 中盤 | 42% | 18% | 23% |
| 中盤〜終盤 | 48% | 23% | 30% |
| 終盤 | 56% | 29% | 39% |
| 最高難易度 | 65% | 36% | 49% |

プレミアム追加抽選は既存の報酬と独立しています。抽選に当たった場合はリストから1種類を追加します。既存の奇跡報酬（0.1〜0.3%）は維持。終盤の大当たり0.6%、最高難易度1.4%に調整しました。

Simply Swords / Simply Moreのユニーク武器は元MODの特殊抽選に任せ、HLOによる直接追加は無効のままです。

GitHubに解凍した中身をアップロードし、Actionsでビルドしてください。既存JARと同時導入しないでください。`loot_v04.json`や`expansion_v08.json`を編集して再ビルドすれば出現率を変更できます。ゲーム内設定ファイルは未実装です。

**注意:** GitHubビルド・Minecraft起動・専用サーバー動作は未検証です。新規テストワールドで確認してください。

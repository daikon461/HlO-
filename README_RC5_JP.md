# RC5 プレミアム秘宝追加版

RC4の全機能を維持し、独立抽選のプレミアム装備を追加します。剣（ドロップ増加）、斧（幸運）、ブーツ（落下耐性）、弓（フレイム）、エンチャント本の5種類です。

| 段階 | プレミアム追加抽選率 | 基準レベル |
|---|---:|---:|
| 序盤 | 1.5% | II |
| 序盤〜中盤 | 2.5% | III |
| 中盤 | 4.5% | IV |
| 中盤〜終盤 | 7% | V |
| 終盤 | 12% | VII |
| 最高難易度 | 20% | IX |

`legendary_v05.json` の設定を編集して再ビルドできます。これは**通常のエンチャント**であり、Apotheosis専用アフィックスや宝石を生成するものではありません。Apotheosisの実際のJARが未提供のため、その独自APIを用いた実装は保留しています。

GitHub ActionsのビルドとMinecraft内動作は別途確認してください。RC4以前のJARとは同時導入しないでください。

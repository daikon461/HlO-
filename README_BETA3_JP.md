# HLO v1.1 Beta 3 — エンチャント装備出現率のワールドティア連動

Minecraft 1.21.1 / NeoForge 21.1.209 / Apotheosis 8.8.0。

## 変更内容
構造物難易度別のエンチャント装備プール（鉄・ダイヤ・ネザライト装備の3候補）の追加抽選確率を、ワールドティアに応じて次の基準値に変更します。

| World Tier | 基準確率 |
| --- | ---: |
| Haven | 12% |
| Frontier | 22% |
| Ascent | 38% |
| Summit | 58% |
| Pinnacle | 80% |

構造物難易度補正：starter ×0.75 / early_mid ×0.85 / mid ×1.00 / mid_late ×1.08 / late ×1.15 / apex ×1.20（最大95%）。

**確率はHLOの専用エンチャント装備プール1回の抽選値です。** チェスト全体の「エンチャント装備を1個以上得る確率」とは異なり、既存の別報酬プールや他MODの抽選は別です。

前版のワールドティア別エンチャントレベル補正、秘宝、Apotheosisアフィックス・宝石、構造物別6段階難易度は維持。

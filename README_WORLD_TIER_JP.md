# HLO v1.1.0-beta1: Apotheosis ワールドティア連動

Minecraft 1.21.1 / NeoForge / Apotheosis 8.8.0 対象。

## 今回実装した内容

既存の構造物別6段階報酬は維持。Apotheosisアフィックス装備と宝石の**追加抽選確率**のみ、Apotheosisのワールドティアに応じて変更します。

- Haven: 従来の55%
- Frontier: 従来の80%
- Ascent: 従来の100%
- Summit: 従来の130%
- Pinnacle: 従来の165%

各追加抽選の確率上限は95%。構造物ごとの従来の基準確率を掛け合わせます。

Apotheosis 8.8.0の `apotheosis:has_world_tier` 戦利品条件を利用します。プレイヤー/ティア情報が取得できない戦利品生成では、これらの追加抽選は発生しない場合があります。

## 未実装

HLO独自のエンチャントレベル・秘宝・素材などの報酬全体をワールドティアに応じて動的に変更する機能は**未実装**です。これらは従来どおり構造物別6段階のままです。今回の版はv1.1完成版ではなくベータです。

## 検証

GitHub ActionsでJARビルド後、Apotheosisのティアを切り替えて新規生成チェストで比較してください。`/loot` コマンドはティア情報を伴わず追加抽選が発生しない可能性があるため、実チェストで確認してください。

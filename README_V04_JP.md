# Hardcore Loot Overhaul v0.4 (検証版)

Minecraft 1.21.1 / NeoForge 21.1.209 / Java 21。

## 更新点
- 戦利品250件を6段階に分類し、各テーブルの報酬を構造物名に基づき調整。
- v0.1の初期報酬に含まれていた、通常チェストでもネザライト素材などが高確率で出る問題を軽減。
- 魔術・工業・冒険系の報酬に構造物ごとの重点を設定。
- 最高難易度の大当たりは0.6%、終盤は0.2%（倍率1.0の場合）。
- loot_v04.json の倍率を変更して再ビルド可能。**ゲーム内設定ファイルではありません。**
- tier_report.csv をビルド時に生成。

## ビルド
ZIPを解凍して中身をGitHubのリポジトリ直下に配置。`.github/workflows/build.yml` が必要。Actionsでビルド。
`generate_loot_data.py` → `upgrade_v04.py` の順に実行。古い upgrade_v02.py / upgrade_v03.py は呼び出さないこと。

## 制約
- MODアイテムの存在チェックは実行時には行っていません。4種類のMODを導入した構成で検証してください。
- 難易度は構造物名のヒューリスティックによる暫定分類。
- GitHub Actions / 実ゲームのビルド・起動は未検証。
- この版は戦利品データの改善が中心で、Java側の設定GUIなどはありません。

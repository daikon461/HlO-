# RC4 秘宝・エンチャント強化版

RC3の豪華報酬・段階別エンチャント装備を維持し、独立抽選で複数エンチャント付き装備とエンチャント本を追加します。

| 段階 | 秘宝抽選確率 | ダメージ増加/効率強化の目安 |
|---|---:|---:|
| 序盤 | 4% | II |
| 序盤〜中盤 | 7% | III |
| 中盤 | 11% | IV |
| 中盤〜終盤 | 16% | V |
| 終盤 | 24% | VII |
| 最高難易度 | 34% | IX |

剣・チェストプレート・ツルハシには耐久力を含む複数エンチャントを付与。エンチャント本には耐久力と修繕を付与します。数値は `relic_rewards.json` から変更して再ビルドできます。

**重要**：Apotheosis専用のアフィックス、レアリティ、ソケット、宝石の生成APIには未対応です。通常のエンチャント付き戦利品を強化したもので、Apotheosis自体の上限を変更しません。ゲーム内動作とGitHubビルドは未検証です。
